# KubeFacet v0.2.0

First public release

## Highlights

- First release under the KubeFacet project, Go module, and Kubernetes API identities.
- Publishes the manager as `ghcr.io/steeltanuki/kubefacet:0.2.0` and the chart as `oci://ghcr.io/steeltanuki/charts/kubefacet`.
- Keeps the existing typed view, selection, aggregation, authorization, admission, and reconciliation behavior.

## Upgrade considerations

- This release intentionally changes the API group and resource Kinds. It does not convert existing resources or support an in-place Helm upgrade from the earlier project identity.
- Review [the migration procedure](../migration-from-kubeseer.md) before installing KubeFacet in a cluster that has the previous operator installed.
