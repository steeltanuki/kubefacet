# KubeFacet v0.2.1

## Highlights

- Correct the webhook certificate directory and CA file patterns in the Helm
  values JSON Schema so Artifact Hub can parse the chart schema.
- Preserve the existing absolute-path and NUL-character validation for both certificate paths.

## Upgrade considerations

- This patch changes no Kubernetes API, CRDs, or chart value names, so no
  resource migration or additional configuration is required.
- After the v0.2.1 image and chart are publicly available, upgrade with the
  normal Helm procedure; existing values remain valid.
